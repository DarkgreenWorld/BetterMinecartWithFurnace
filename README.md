# 更好的动力矿车（Better Furnace Minecart）

Minecraft Java 版 26.3 的 Fabric 模组，**纯服务端**：只装在服务器上即可，原版客户端可以直接进入。不依赖 Fabric API。

## 功能

- **逐渐加速**：点着的动力矿车不再一 tick 就达到最高速度，而是按 `acceleration`（默认 0.01 格/tick²，约 1 秒到最高速度）匀加速。达到最高速度后完全交还给原版逻辑，推其他矿车、爬坡的力度不变。
- **动力铁轨**（新旧两套矿车物理都适用）：
  - 未充能的动力铁轨按原版普通矿车的逻辑刹车：发动机在上面不出力，速度每 tick 减半，全速驶入也会在 1 格内停下。停住期间如果是点着的，燃料照常消耗；铁轨充能后自行逐渐加速离开。
  - 充能的动力铁轨对**正在燃烧**的动力矿车等同于普通铁轨，不加速，也不会把靠着方块的静止矿车弹出去。
  - **空的、熄灭的**动力矿车和原版一样，可以用充能的动力铁轨加速、发车。
- **水桶熄灭**：主手拿水桶右键点着的动力矿车，或者用装有水桶的发射器正对矿车所在的那一格并激活，都可以将其熄灭。剩余燃烧时间和行进方向都会保留，水桶不消耗。熄灭后保留动量，和原版燃料烧完时一样滑行（平地约 10 格）。
  - 发射器面前那一格只要有动力矿车就不会倒水（矿车没在燃烧时发射失败）；没有动力矿车时是原版行为，会把水倒出来。
- **漏斗补充燃料**：没在燃烧的矿车（熄灭的或空的）正上方有**朝下、未被红石锁住**的漏斗时，每 8 tick 从里面取 1 个煤炭/木炭，直到加不进为止（原版上限 32000 tick，即剩余超过 28400 tick 时不再取）。漏斗只补充燃烧时间，**不会点燃**矿车：空矿车加了燃料后进入熄灭状态，原地不动。燃烧中的矿车不会从漏斗取燃料。
- **重新点燃**熄灭状态的矿车（三种方式）：
  - 主手拿打火石右键（消耗 1 点耐久）；
  - 主手拿煤炭/木炭右键，和原版加燃料一样，朝远离玩家的方向走（燃料已满加不进时无效，请用打火石）；
  - 装有打火石的发射器正对矿车所在的那一格并被激活（消耗 1 点耐久）。
  - 打火石和发射器点燃时按熄灭前的方向继续走；空矿车由漏斗加的燃料没有“之前的方向”，则朝远离玩家/发射器的方向走。
  - **完全空的动力矿车没有燃料，打火石（手持或发射器）点不着**，必须先加燃料。

熄灭状态用实体标签 `better_minecart_with_furnace.extinguished` 记录，也可以用命令操作：

```
/tag @e[type=minecart_with_furnace,sort=nearest,limit=1] add better_minecart_with_furnace.extinguished
```

## 配置

首次启动后生成 `config/better_minecart_with_furnace.properties`：

```properties
acceleration=0.01
```

单位是格/tick²，允许范围 0.001 ~ 0.06。0.06 是充能动力铁轨的加速度，超过会被限制为 0.06。修改后重启服务器生效。

## 构建

需要 JDK 25 和 Gradle 9.7 以上：

```bash
gradle build
```

产物在 `build/libs/better-furnace-minecart-1.0.0.jar`，放进服务器的 `mods` 文件夹。任何支持 26.3 的 Fabric Loader 都可以（用到了 Loader 自带的 MixinExtras）。
